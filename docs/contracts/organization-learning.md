# Organization Learning Contract

## Objective

Reduce future manual intervention for the same class of intent without over-generalizing from one interaction.

## Learning classes

- preference;
- workflow;
- tool-selection;
- organization-composition;
- capability;
- knowledge;
- policy;
- non-reusable observation.

## Learning sources

- explicit user preference;
- repeated edits;
- workflow corrections;
- editor/tool selection;
- organization comparison;
- Arena expert interventions;
- ToolGapSignal;
- scoped knowledge.

## Human takeover rule

A manual edit is high-value learning evidence only when preceding state, changed artifact, resulting revision and learning permission are available.

## Personalization boundary

A user preference is not a global rule. Global promotion requires cross-run evidence or an explicit authored rule and all normal promotion gates.

## Capability frontier

The Lab must measure where autonomous execution succeeds, where users repeatedly correct, where assistance is needed, and where human experts are required.

The goal is safe frontier expansion.

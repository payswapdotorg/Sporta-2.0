A5 manual takeover.

A11 organization candidate from learning.
A12 auditable/reversible promotion.
A13 authorized sports source -> SWM -> two materially different realities.
A14 provider fallback or clean manual fallback.
A15 fresh-machine/local installation.
A16 hosted preview with truthful capacity state.
A17 complete intent -> organization -> execution -> artifact -> user edit -> learning -> capability gap -> Arena -> result -> candidate -> evaluation -> promotion loop.

Evidence must distinguish real execution from fixtures. No gate may be weakened to convert a failure into success.

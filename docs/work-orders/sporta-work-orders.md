# Sporta 2.0 Work Orders

## Universal worker law

Every worker reads the architecture lock and packet before editing. Workers never treat chat as authority.

Every worker report must contain:
WORK ITEMS / CHANGED FILES / TESTS / REAL EVIDENCE / FIXTURE EVIDENCE / CONTRACT CHANGES / RIGHTS-PROVENANCE / PERFORMANCE / SECURITY / RISKS / BLOCKERS / DEVIATIONS / NEXT DEPENDENCIES

Workers never self-close milestones.

## TL-only

TL0: repository conversion, architecture policy, contracts and public export strategy.

TL1: integration and root/lockfile reconciliation.

TL2: end-to-end orchestration and cross-domain acceptance.

TL3: final drift audit, provider fallback, release/readiness.

intent -> organization -> AgentRuntime -> artifact -> external editor -> user edit -> learning -> capability gap -> Arena -> expert result -> candidate -> evaluation -> promotion

without changing the canonical WorkGraph or artifact lineage.

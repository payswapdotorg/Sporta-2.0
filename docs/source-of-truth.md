# Sporta 2.0 — Repository Source of Truth

This repository is the sole implementation authority for Sporta 2.0.

## Authority order

1. checked-in source;
2. architecture lock and canonical contracts;
3. project state, dependency graph, roadmap, work orders and acceptance gates;
4. committed execution/evidence records;
5. cited upstream repositories/specifications;
6. chat history is not authoritative.

A fresh TL must be able to continue from a clean checkout without access to this conversation.

## Upstream

Sporta 2.0 is a fork of zai-org/zcode. ZCode remains the generic execution/workspace substrate unless an accepted ADR changes that boundary.
